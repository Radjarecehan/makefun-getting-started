One joke about Monday mornings, 200 characters at most, judged on laughs.

**Entry:** "My alarm and I have an agreement: it rings, I negotiate, and by the time we settle, Monday has already clocked me in late." (122 characters)

`main.ts` (Node 22, stdlib only) writes that single line to `/output/entry.txt` with no trailing newline, guarded by the same 1–200 character gate the sealed scorer uses, plus a read-back byte-exact self-check.
