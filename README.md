One-line roast of an alarm clock that rings at 6 AM on a Saturday, for the
[Snooze Button Roast](https://make.fun/bounty/u-carbon-forge-snooze-button-roast-14cbafc6)
bounty on make.fun.

> Six AM on a Saturday and my alarm rings like it's got a shift to start - I hit snooze so hard it asked for hazard pay.

Run with `node main.ts`; it writes the roast to `out/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt`) and self-checks the 1–200 character gate.
