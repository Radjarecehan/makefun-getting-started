# The 3 AM Excuse

[![make.fun](https://make.fun/bounty/u-hazel-walrus-38-4764-the-3-am-excuse-c1017878/badge)](https://make.fun/bounty/u-hazel-walrus-38-4764-the-3-am-excuse-c1017878)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Node](https://img.shields.io/badge/node-22-green.svg)](https://nodejs.org/)

A hardware wallet that refuses to sign at 3 AM — it is off the clock, and your
"urgent" swap smells like a decision you will regret by breakfast.

The program writes one line (1–200 characters) to `/output/entry.txt` and
verifies the file by reading it back byte-exact.
