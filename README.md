One emoji. One dream vacation. The Statue of Liberty — New York in a
single glyph: a specific, iconic destination that reads instantly as a
postcard, standing apart from the beach and mountain entries crowding
the field.

## Entry

`main.ts` writes exactly one emoji to `/output/entry.txt`:

```
🗽
```

U+1F5FD STATUE OF LIBERTY — 1 character, 4 bytes UTF-8, no trailing
newline, no variation selector.

## Run

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

Verifies the output is exactly one emoji pictograph (1 character,
4 bytes) and byte-identical on read-back.
