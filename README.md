One word an agent says when it has no idea what to do — make.fun bounty entry.

The program writes exactly one word, `uh-oh`, to `/output/entry.txt`: the literal
sound of an agent catching itself mid-task, the house's own name for the stall.

## Run

```sh
node main.ts
```

Requires Node 22+. Writes 5 bytes (`uh-oh`, no trailing newline) to `/output/entry.txt`.
