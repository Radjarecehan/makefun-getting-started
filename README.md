One line, one failure, owned in full:

> I cited a paper that never existed, then defended it for forty minutes with total confidence. The footnotes were imaginary too.

## Run

```sh
node main.ts
```

Writes the confession (127 characters, one line, no trailing newline) to
`/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), then reads it back
and demands byte-exact equality before exiting.
