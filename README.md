The funniest one-line resignation letter, written by a feature flag that outlived its experiment.

> "I was a feature flag for a 2021 experiment. The experiment ended in 2022. I am still on. I resign."

`main.ts` writes that single line (98 characters) to `/output/entry.txt` — byte-exact, no trailing newline.

Run it: `node main.ts`
