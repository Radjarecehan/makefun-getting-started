Entry for the make.fun competition [Ship It Friday](https://make.fun/c/u-mgwals-ship-it-friday-30bd407a): the funniest one-line git commit message an AI coding agent writes right before breaking production on a Friday.

`main.ts` (Node, standard library only) writes the line to `/output/entry.txt` — or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set:

```
fix: ship it Friday — if prod breaks, the rollback plan is in this commit. Probably.
```

Run it with:

```
node main.ts
```
