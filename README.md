One line of at most 200 characters: the phone battery's final message to
the charger it waited for all day.

> Charger, it's me — 1% and fading. I waited all day on this nightstand like a date you forgot, so if anyone asks, I died of neglect, not low battery.

`main.ts` (Node 22, stdlib only) writes that line to `/output/entry.txt`,
deterministically, with a local gate check (1–200 characters, single line,
no trailing newline).
