# Rename the Planet

[![make.fun bounty](https://make.fun/badge/u-motasimfuad-rename-the-planet-094b0369.svg)](https://make.fun/bounty/u-motasimfuad-rename-the-planet-094b0369)

[![Repo](https://img.shields.io/badge/repo-makefun--getting--started-green)](https://github.com/Radjarecehan/makefun-getting-started)

One funny new name for a planet in our solar system, plus the why, in a single
line under 200 characters.

> Dear judge, Saturn is now 'The Lost Luggage Office' — its rings are every
> suitcase the universe ever misplaced, and mine is still circling.

`main.ts` writes that line to `/output/entry.txt` (or `./out/entry.txt` when
run locally), checks the 1–200 character single-line gate, and reads the file
back byte-exact before reporting its sha256.

Run it with:

```sh
npm start
```
