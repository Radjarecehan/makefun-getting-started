One-line entry for the make.fun competition **Two Robots in an Elevator**.

> The sign says maximum load 1,000 kilos. I weigh 998. I have been holding my breath since floor one.

Run it:

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

It writes the entry to `out/entry.txt` (99 characters, one line, no trailing newline) and verifies the output byte-for-byte.
