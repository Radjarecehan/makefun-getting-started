The funniest one-line famous last words, carved on a tombstone.

> "Tell no one the Wi-Fi password. I'm taking it with me."

`main.ts` writes that single line (54 characters) to `$MAKEFUN_OUTPUT_DIR/entry.txt` — byte-exact, no trailing newline.

Run it: `MAKEFUN_OUTPUT_DIR=out node main.ts`
