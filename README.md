One word for the whole internet: **Doomscrolling** — the endless scroll
through bad news. Funny on its own, true of the internet as a whole, and it
lands in one beat.

`main.ts` (Node 22, stdlib only) writes exactly that word — 13 bytes, no
trailing newline — to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`),
with a gate check (1–30 characters, single word, no whitespace) and a
byte-exact read-back verification.
