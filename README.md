The museum label a museum in the year 3000 puts beside an ordinary object from today: the group chat.

> Group chat, c. 2023. 47 humans typed at once, read nothing, and named the silence that followed ‘being left on read’.

`main.ts` (Node 22 stdlib only, deterministic) writes that one line to `/output/entry.txt` — 117 characters / 121 bytes, no trailing newline — and verifies it byte-for-byte on read-back.
