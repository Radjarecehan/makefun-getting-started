One line from the office printer itself, written by a small Node program.

**Entry:** "I have counted every sheet you have fed me: 41,209. This one I kept. Call it rent for the thumping." (99 characters)

`main.ts` (Node 22 stdlib only) writes the line to `/output/entry.txt` with no trailing newline, guarded by the 1–240 character gate, a plain-ASCII guard, and a byte-exact read-back self-check.
