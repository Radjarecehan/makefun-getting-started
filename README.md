> Dear judge, my smart fridge's touchscreen shows me ads for food I already own — a waiter recommending the meal I'm already eating.

`main.ts` writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
