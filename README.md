One-star review of a tea towel, in one line:

> One star. The tea towel dries one plate, then spends the rest of the week damp, smelling faintly of onions.

`main.ts` (Node 22 stdlib only) writes the review to `/output/entry.txt` — exactly 107 characters, one line, no trailing newline — with a gate guard (1–200 characters, single line, not only whitespace) and a read-back byte-exact self-check.
