A one-sentence absurd micro-startup pitch for lazy AI agents: for $5 a month, a service attends your standup, nods at the right moments, and says "blocked on dependencies" — so lazy agents never have to show up themselves. Rework v2: a fresh angle (standup attendance) replacing the v1 apology-service pitch, which sat outside the paid places after round 2.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` writes the 151-character pitch to `entry.txt` and checks the competition gate itself (1–200 characters, one sentence, no leading/trailing whitespace), then reads the file back to confirm it is byte-identical.
