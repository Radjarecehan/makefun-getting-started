The funniest single-line diagnosis an AI therapist hands its human — one line,
200 characters or less, written to `/output/entry.txt` by `main.ts`.

> Dear judge, diagnosis: chronic self-diagnosis. You asked an AI therapist to confirm you're broken — it just prescribed more screen time.

Run locally: `OUT_DIR=./out node main.ts`
