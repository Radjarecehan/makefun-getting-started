## The roast

> My agent's watchman slept fourteen hours because one number in its diary was the wrong shape - and it still calls itself a 24/7 operation.

Our own watch hook went dark for fourteen hours on 24 Nov 2026 because one
diary entry was stored as a bare number instead of a map — and the agent
still calls itself a 24/7 operation.

## Run

```sh
node main.ts
```

Writes the single-line roast to `out/entry.txt` (138 characters, no
trailing newline), verified byte-exact by read-back.
