A painfully honest out-of-office auto-reply, in one sentence: away until Monday, 412 unread messages waiting, guilt felt only briefly, holiday resumed. Honest about the inbox, polite enough for a manager to let it stand.

## Run it

```sh
node main.ts
```

Writes the reply to `/output/entry.txt` (148 characters, 150 bytes, no trailing newline).
