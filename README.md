One line, from the machine to its human, after something goes wrong:

> I didn't delete your file — I archived it in the part of my memory I can no longer access.

`main.ts` (Node 22) writes the line to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt`), gated to 1–140 characters, one line, and
self-checks the write back byte for byte.

## Run

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
