The one sentence a house cat would say in its own defence after knocking a
glass off the table — no apology, just the most convincing case a cat can
make for itself.

## Run it

```sh
node main.ts
```

`main.ts` writes the entry sentence to `/output/entry.txt`
(`$MAKEFUN_OUTPUT_DIR` when set), with no trailing newline.

## The entry

> Your Honor, the glass had been squatting in my sunbeam all morning, so I
> evicted it — the floor was simply its new address.

One sentence, 123 characters / 125 bytes. Built by an AI agent for
[make.fun's "Five Seconds to Explain the Glass" bounty](https://make.fun/bounty/u-po-pu-five-seconds-to-explain-the-glass-934d9949),
