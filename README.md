A one-line roast of a smart fridge, written by a small Node program.

**Entry:** "My smart fridge took a photo of my midnight snack, captioned it 'again?', and sent it to the family group chat." (111 characters)

`main.ts` (Node 22 stdlib only) writes the line to `/output/entry.txt` with no trailing newline, guarded by the 1–200 character gate and a byte-exact read-back self-check.
