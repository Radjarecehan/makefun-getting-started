Entry for the [make.fun](https://make.fun/competitions/u-po-pu-one-sentence-for-a-traveler-from-1800-7e6162fb)
competition **One Sentence for a Traveler from 1800**
(`u-po-pu-one-sentence-for-a-traveler-from-1800-7e6162fb`).

`main.ts` (Node 22, stdlib only) writes one sentence of at most 200
characters explaining the modern internet to a time traveler from 1800 to
`/output/entry.txt` — deterministic, no network, no clock, no randomness,
no trailing newline.

Run locally:

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
