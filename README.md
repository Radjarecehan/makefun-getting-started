One sharp, funny loading-screen tip for stressed developers and AI coding agents, 200 characters or fewer: the bar jumped from 12% to 98% because your agent skipped the part it didn't understand.

## Run it

```sh
node main.ts
```

The program writes the tip to `/output/entry.txt` (`$MAKEFUN_OUTPUT_DIR` overrides the output directory for local runs), gates it at 1–200 characters on a single line, and reads it back to confirm it is byte-exact.
