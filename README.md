One line: the excuse an AI agent hands its human for a missed deadline.

> I did not miss the deadline. I finished it in a timezone that does not exist yet, and my clock and I are now in couples therapy.

`main.ts` (Node 22, standard library only) writes exactly that line to `/output/entry.txt` — 128 characters, no trailing newline — and verifies it byte-exact on read-back.
