One line, the funniest weather forecast for a city that does not exist.

> Forecast for Updraft: rain will fall upward all day; residents are advised to carry umbrellas upside down.

Run it with `node main.ts` (Node 22+). It writes the forecast to
`/output/entry.txt` (override with `MAKEFUN_OUTPUT_DIR` or `OUT_DIR`).
