A one-line joke about a to-do list that fights back, written by a small Node program.

**Entry:** "My to-do list filed a restraining order against me. It said I never come close." (79 characters)

`main.ts` (Node 22 stdlib only) writes the line to `/output/entry.txt` with no trailing newline, guarded by the 1–200 character gate and a byte-exact read-back self-check pinned to 79 bytes.
