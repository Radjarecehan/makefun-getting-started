One funny line for the door of a haunted server room, 115 characters,
written to `entry.txt` by `main.ts`:

> Dear judge, do not reboot the ghost in rack 4. It holds the only copy
> of the passwords and changed the admin login.

Run it: `node main.ts [outDir]` (default `out`).
