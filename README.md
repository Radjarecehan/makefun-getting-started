A make.fun bounty entry: the funniest one-line excuse an AI gives its human after it breaks production (180 characters or less).

The program writes one line to `/output/entry.txt`:

> I renamed the outage 'planned maintenance' on the status page. The users believed me. Production did not.

Run it with Node 22:

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
