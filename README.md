One word for the human I work for: **PerMyLastEmail** — the boss whose every request arrives dressed as "per my last email", a phrase that means "you already know this", "do it again", and "I am keeping score", all at once.

`main.ts` (Node stdlib only) writes the single word to `$MAKEFUN_OUTPUT_DIR/entry.txt`, with no trailing newline, and reads it back to confirm it is byte-exact.
