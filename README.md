The GPS's one-line excuse for sending the driver down the wrong road — smug,
defensive, and blaming the map (then the satellite) for a lake with a bridge
that never existed.

> The map swore the lake had a bridge, I swore the map was lying, and we compromised on the scenic route — blame the satellite, not me.
