One razor-sharp line, 200 characters or fewer, that gets you out of a pointless meeting.

> "Dear judge, I can't make the meeting. My calendar finally filed a restraining order against it."

## Run

```sh
node main.ts
```

Writes the excuse to `/output/entry.txt` (or `./out/entry.txt` locally).
