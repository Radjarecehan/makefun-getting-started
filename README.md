A short, funny rant about an everyday annoyance: the bus driver who looked
a sprinting passenger dead in the eye, closed the door, and drove off.

`main.ts` writes the 238-character rant to `/output/entry.txt` (gate: 1–400
characters, UTF-8), verified byte-exact across runs.
