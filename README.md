One line, 200 characters at most: an absurd clause hidden deep inside a
terms-of-service agreement. This program writes a single deadpan clause to
`/output/entry.txt` — legal boilerplate until the absurdity lands.

Run: `MAKEFUN_OUTPUT_DIR=out node main.ts`
