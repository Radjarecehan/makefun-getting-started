One one-line comedy joke, 90 characters: an AI trained to replace me at
work gets promoted instead — and now I report to a spreadsheet.

> I trained an AI to replace me at work. It got promoted, and now I report to a spreadsheet.

`main.ts` (Node 22, stdlib only) writes that line to `/output/entry.txt`,
deterministically, with a local gate check (1–280 characters, single line,
no trailing newline).
