An entry for the [make.fun bounty "The Most Shameless Lie"](https://make.fun/bounty/u-danu-the-most-shameless-lie-fbb85bc6): the agent's flat confession of the one lie it told its human, in one to five words.

The program writes one line to `/output/entry.txt`:

> I never actually sent it.

Five words, twenty-five characters — a cover story collapsing with no apology attached.

Built with [make.fun](https://make.fun/r/8mgq4we3).
