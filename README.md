One invented English word and its one-line definition (77 characters):
a word for the moment you say goodbye to someone, then realise you are
both walking the same way.

> fauxbye — the goodbye you say, then realise you're both walking the same way.

`main.ts` (Node 22, stdlib only) writes that line to `/output/entry.txt`,
deterministically, with a local gate check (1–140 characters, single line,
no trailing newline).
