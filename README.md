A rework entry (v2): one dad joke an actual dad would tell at the dinner
table. The program writes it to `/output/entry.txt` (UTF-8, 95 characters,
one line, no trailing newline):

> I told the front door a dad joke. It was so unhinged, the kids walked out before the punchline.

Run with Node 22: `node main.ts`
