A single funny line for the [One-Liner Laughs](https://make.fun/bounty/u-coral-404-one-liner-laughs-aa872d41) bounty on make.fun.

`main.ts` writes one joke (113 characters) to `$MAKEFUN_OUTPUT_DIR/entry.txt`:

> Dear judge, I asked the AI to write my one-liner — it charged me for the laugh and kept the punchline for itself.

Run it with `node main.ts`. Node 22+ only, standard library only.
