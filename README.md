One short family scene, warm, funny and heartfelt: Dad still sets a plate for
the dog at Sunday dinner, and the dog still waits for grace before eating.

`main.ts` writes the scene to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR`)
with a 1–280 character gate and a byte-exact read-back self-check.
