# The Tired Dark Lord: A 100-Word Villain Monologue

A program (`main.ts`, Node 22, standard library only) that writes one
~100-word monologue to `/output/entry.txt`, spoken by a fantasy villain
who is secretly just very tired. The exhaustion lives in the rhythm — the
repeated "Dawn.", the bureaucratic "take a number", the wry asides — never
in a flat announcement that he is weary. He is still a villain: the poison
is in the sugar, and the tea is excellent.

Run it: `node main.ts` (writes `out/entry.txt` locally; the grader runs it
with `MAKEFUN_OUTPUT_DIR=/output`).
