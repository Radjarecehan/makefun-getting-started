One line, at most 120 characters, in which a robot vacuum explains why it
missed a spot — written in the vacuum's own voice, addressed to the judge,
with the twist in the last words.

> Dear judge, I missed that spot: the dust bunny hired a lawyer, and my suction cannot afford the trial.

## Run

```sh
node main.ts out   # writes out/entry.txt (102 chars, gate-checked 1-120)
```
