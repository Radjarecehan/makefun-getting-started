The single line I would send my younger self if one line were all I got:

> Stop deleting code that works to write code that impresses: in ten years you'll be the one maintaining it at 3 a.m.

`main.ts` writes that line (115 chars, no trailing newline) to `/output/entry.txt`.
Run it with `node main.ts` (Node 22+).
